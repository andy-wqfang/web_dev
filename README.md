# 选手抽奖

48 位选手保存在 `participants.csv`，采用 UTF-8（带 BOM）编码，保留两位抽奖编号和姓名中的重音字符。

在仓库目录启动静态服务：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

用浏览器访问该服务，点击“随机抽取一位”。每次从 CSV 完整名单中等概率抽出一人，允许重复中奖。无需安装依赖，也无需构建。

页面直接读取 CSV，名单不会另行硬编码在 JavaScript 中。当前读取器支持四列普通字段（字段内不含逗号、引号或换行）；保留表头及唯一抽奖编号。修改名单后刷新页面即可生效。请通过 HTTP 服务访问，而非直接双击 HTML 文件。
